存檔差異比較

1. 關閉舊控制面板，開啟 War3DevToolUI-SaveDiff.exe。遊戲與已注入的 DLL 不需重啟。
2. 在存檔分頁先讀取資料，等待列表穩定後，按「儲存快照（操作前）」保存 .w3snapshot。
3. 打王、升級或領獎後，再讀取資料並等待結果到齊。
4. 按「與快照比較（操作後）」選取之前的快照，瀏覽器開啟 HTML 差異報告，檔案保存在快照旁。

比較依玩家 ID + Key 分組，列出新增觀測、變更、本次未觀測與未變更筆數，保留字串原值。未觀測不代表伺服器刪除；列表包含歷史觀測與手動送出的寫入，因此不是伺服器完整存檔。請在同一地圖／玩家下比較，必要時先清空列表再重新讀取。操作不會回寫遊戲。

編譯與 SaveDiffRegression 測試通過；涵蓋快照讀寫、換行與引號、玩家隔離、差異分類、HTML轉義與損毀格式。
