# 存檔差異比較

1. 執行 `bin/War3DevToolUI.exe`，進入存檔分頁。遊戲與已注入的 DLL 不需因比較而重啟。
2. 讀取資料並等待列表穩定，按「儲存快照（操作前）」保存 `.w3snapshot`。
3. 在遊戲內完成要觀察的行為，再讀取資料並等待列表穩定。
4. 按「與快照比較（操作後）」選取先前快照。程式會在快照旁產生 HTML 差異報告並開啟瀏覽器。

比較以玩家 handle 與 Key 分組，顯示新增觀測、變更、本次未觀測與未變更筆數，並保留字串原值。「未觀測」不表示伺服器刪除；列表包含歷史觀測值，並非伺服器完整存檔。請在同一地圖與同一玩家下比較，必要時先清空列表再重新讀取。比較不會寫入遊戲。

`SaveDiffRegression` 涵蓋快照讀寫、特殊字元、玩家隔離、差異分類、HTML 跳脫及損毀格式。
